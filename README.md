# HMAC-Generator
A web-based application to generate HMAC (Hash-based Message Authentication Code) using different algorithms like SHA-256, SHA-384, and SHA-512. This tool allows users to securely generate HMAC values for a message or a file.

To execute the codes,
* git clone https://github.com/srini2805/HMAC-Generator.git
* cd HMAC-Generator

--> Since it's a web-based application, you don't need any server setup. You can simply open the HTML file in any web browser (e.g., Chrome, Firefox, etc.) to use the application.
--> Open the main HTML file, typically index.html, by double-clicking it. The web application should load in your browser.

To use,
1. Open the application in your browser.
2. Select the hashing algorithm (e.g., SHA-256, SHA-384, SHA-512).
3. Enter the message or file you want to generate the HMAC for.
4. Click on the Generate HMAC button to see the HMAC output for the provided input.
